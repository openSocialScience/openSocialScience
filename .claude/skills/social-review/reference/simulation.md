# 仿真论文的审稿成见（`sim:` 来路）

`paper_rendered.md` 是仿真论文的成稿时（运行目录带 `sim_state.json`），三位
互盲审稿人的**成见**（原版三顶帽子：识别 / 替代解释 / 局限，见
`blind-discipline.md`）换一套问法——盯的位置不变，问题换了，因为
仿真数据的头号威胁是模型伪影，不是观察性混淆（这条判断的细节见
`.claude/skills/social-research/stages/7.5-identification.md` 的 sim 分支）。

## 三位换一套问法

| 位 | 原版成见 | 仿真版成见 |
|---|---|---|
| 识别 | 「这不是因果」 | **「这是涌现还是模型先验」**——条件间的差异是模拟机制真的跑出来的，还是这个 LLM 对这类议题本来就有固定立场，条件怎么设都会收敛到同一个答案 |
| 替代解释 | 「还能被别的解释」 | **「提示词换个说法结论还在吗」**——访谈问题、角色设定换一种问法，结论会不会跟着变；没跑过提示词变体的，这条问不出答案，得写进局限，不能假装问过 |
| 局限 | 「该写的没写」 | **「五条局限写全没」**——小人效度、版本漂移、提示词敏感、污染声明、单一模型，一条不能少（细则见 `.claude/skills/social-paper/reference/simulation.md`） |

`--emphasis` 仿真版三句：

```bash
oss review --paper --level deep --run <目录> --round 1 --emphasis "这是涌现还是模型先验：条件间差异是模拟机制真的跑出来的，还是模型对这类议题的固定立场"
oss review --alternatives --level deep --run <目录> --round 1 --emphasis "提示词换个说法结论还在吗：访谈问题与角色设定的措辞敏感性有没有跑过、没跑过有没有写进局限"
oss review --paper --level deep --run <目录> --round 1 --emphasis "五条局限写全没：小人效度、版本漂移、提示词敏感、污染声明、单一模型"
```

## 桌审多看两条

桌审（`oss review --desk`）原有十条之外，仿真论文再加两条。**这两条都是**
**机器兜不住、只有人看得出来的那一半**——不是复查机器已经查过的东西。

**一、配料单里没牙齿的那五项报得够不够。**

十二项里有七项 `paper check` 会去正文里找它的值（模拟器、版本、模型、网关、温度、
轮数、重复次数），机器拦得住。剩下五项**一点机器兜底都没有**：

- `prompts` —— 提示词**原文**，不是转述。转述等于没报：换个说法结论可能就变了
- `population` —— 这批小人是谁、怎么设定的
- `interview_plan` —— 第几轮问、问几次
- `contamination_note` —— 模型训练语料是否可能见过这个议题，「不确定」也要写
- `conditions` —— 各条件是什么意思（机器只核条件名在不在货箱里，不核描述）

这五项漏了或含糊，是方法节不诚实，跟「局限没写全」是两类问题。

**二、ODD 第四节「设计概念」写清楚没有，以及 `pattern` 那条面向模式的验收成不成立。**

ODD 七节里，第四节（涌现、适应、交互、随机性、观测）**没有任何机器兜底**，
而它恰恰是最容易含糊过去的一节。另外计划里 `pattern` 那一栏写的是「模型跑对了
该出现哪个现实里已经观察到的规律」——要看两件事：**那个模式是不是事前就定下的**
（不是看完结果反过来挑一个对得上的），以及**模型重现的是不是作者声称的那个**。
Grimm 的面向模式验收，事后挑模式就等于没验收。
