# 占位符、三张表、图、引用、校验

## 铁律：正文里不许出现裸数字

**统计结果一律写成占位符：**

```
估计结果显示效应为 {{result:main.coef}}
（标准误 {{result:main.se}}，p {{result:main.p}}），样本量 {{result:main.n}}。
```

数字由程序在渲染期从 `results.json` 填入。**这样写得再差也不会编造数字。**

先看有哪些可以引用：

```bash
oss paper check --run <运行目录>
```

**三个命名空间**，因为诚实的论文要引用三处的数字：

| 命名空间 | 引用什么 | 例子 |
|---|---|---|
| `result` | 估计结果 | `{{result:main.coef}}` `{{result:main.se}}` `{{result:main.p}}` `{{result:main.n}}` |
| `power` | 功效报告 | `{{power:power}}` `{{power:design_effect}}` `{{power:n_effective}}` |
| `diag` | 回归诊断 | `{{diag:组内 R²}}` `{{diag:吸收的自由度}}` `{{diag:共线诊断（VIF）}}` |
| `robust` | 稳健性检验 | `{{robust:R1 结果换职业声望/main.coef}}`（label 与后半用 `/` 隔开）；引这一项自己的诊断用 `{{robust:<label>/diag.有效 F}}`、`{{robust:<label>/diag.AR 区间}}` |
| `bin` | 分箱估计 | `{{bin:college=1.0/last.slope}}`（`first` / `last` / 箱号） |
| `cite` | 文献引用 | `{{cite:W2079007828}}` 或 `{{cite:10.1086/321300}}` → 渲染成 `Breen (2010)`（英文稿自动用 `et al.`） |
| `fig` | 诊断图 | `{{fig:robustness}}` → 渲染成嵌入正文的图片 |
| `table` | 三张表 | `{{table:descriptives}}` `{{table:main}}` `{{table:robustness}}`（另有 `cohorts`、`event`）→ 渲染成表，数字与表注全部来自结果文件 |

**局限那一节多半要用 `power` 和 `diag`**——功效不足、设计效应、
有效样本量掉了多少，这些是审稿人最先看的，也最不该手打。

**稳健性那一节要用 `robust` 报具体数值，不要只写「同号同显著」。**
一句「稳健」藏得住太多东西：量级掉了一半算不算？某一项的置信区间跨过零算不算？
`results.json` 的 `robustness` 里每一项都能引用——**包括跑不动的那几项**，
它们没有结果本身就是信息，省掉的话读者分不出「没做」和「做了但不好看」。

### 三张表必须有：描述统计、主结果、稳健性

评审第十次验收跑：「所有系数用散文报出来。没有描述性统计表，没有回归表——
**任何量化论文这都是硬伤**，读者无法复核、无法引用、无法比较。」

表跟数字同一套机制：占位符，渲染期从 `results.json` 排出来，**表注也是生成的**
（估计量、固定效应、聚类、样本筛选、星号约定都来自计划），不手写。

```
*Table 1. Descriptive statistics.*
{{table:descriptives}}

*Table 2. Main estimates.*
{{table:main}}

*Table 3. Robustness.*
{{table:robustness}}
```

- **表注在占位符上一行**（期刊惯例：表注在上、图注在下），以 `*Table N.` 开头，编号自己维护
- `descriptives` 进数据一节，`main` 进结果一节，`robustness` 进稳健性一节
- `sample`（样本构建日志：每步剩多少、谁掉了）进数据一节，或按 `diagnostics.样本构建` 写一段
- 分批估计（`did_cs`）再加 `{{table:cohorts}}`（各批各自的效应）；事件研究可加 `{{table:event}}`
- 正文引表：**"Table 2 reports…"，然后只解读，不把表里的数字再念一遍**
- 没有 `{{table:main}}` 校验只警告，**导出 Word 时拒绝**
- 英文稿的表里不能有中文：稳健性标签（`plan.json` 的 `label`）用英文写
- 跑不动的稳健性项会以 "— (not estimated)" 出现在表里，**正文要说一句为什么**

### 图必须嵌进正文

一篇没有图的定量论文不是成品。**至少嵌两张**：

```
{{fig:robustness}}

*Figure 2. Robustness across pre-registered specifications.*
```

- 结果节：`{{fig:coef}}`（主系数）和 `{{fig:robustness}}`（森林图）挑其一或都要
- 有交互项：`{{fig:marginal}}` **必须嵌**——形状断言全靠它
- 因果设计：`{{fig:event}}`（逐年效应）
- 图注写在占位符下一行的斜体里，编号自己维护——**没有图注校验拒绝**
  （Word 里图的题注就是这一行；验收跑的 Word 里每张图下面是个裸露的 "coef"，就是因为图注没接上）

**进论文的图要用发表样式、英文**：

```bash
oss figure coef --run <运行目录>                     # 缺省 --lang zh（中文期刊体例）；英文稿传 --lang en
```

它画出 `fig_coef.png`（300 dpi）和 `fig_coef.pdf`（矢量），并在 `fig_coef.json` 里
记下语言和一条**建议图注**——图注照它改写，别自己编图里没有的东西。
**英文稿里嵌了中文版的图，校验会拦**（验证跑的英文 Word 里四张图全是中文标题，没人拦）。
稳健性图的标签直接来自 `plan.json` 的 `label`——写计划时就用英文。
诊断图（结构、缺失、簇、VIF）是给你看的，**不进论文**。

引一张不存在的图会被校验拦下（跟引不存在的估计同样处理）。

### 引用也不许手打

**跟数字同理：手打的引用看起来跟真的一模一样。**

```
不许写：Breen 发现教育扩张促进了流动
只能写：{{cite:W2079007828}} 发现教育扩张促进了流动
渲染成：Breen (2010) 发现教育扩张促进了流动
```

编号从 `literature.json` 里复制（`paper_id` 或 `doi` 都行），**不用打字**。

两种写法，按句子需要选：

```
叙述式  {{cite:10.2139/ssrn.975892}} found that …     → Kudamatsu (2007) found that …
括注式  … improves health {{citep:10.2139/ssrn.975892}}.  → … improves health (Kudamatsu 2007).
多篇    … is well established {{citep:W2921373492;W2007372263}}.  → … (Bollyky et al. 2019; Kudamatsu 2012).
```

**括注式放在它支撑的那句话或从句的末尾**，不要放在句首。验收跑的成稿里有
「(Colagrossi et al. 2020) A meta-analysis finds …」这种写法——括注挂在句子前面，
编辑第一眼就会改。两篇以上用一个 `citep`、id 之间用分号，不要连写两个括注。

正文末尾写 `{{references}}`，参考文献列表**自动生成**——
引了一定在里面，没引的不许出现（后者是很常见的凑数手法）。
导出 Word 时引用和参考文献由 citeproc 按目标期刊的样式（Chicago / APA / ASA）重排，
**你不用管格式**，只管引对。

**两种裸引用，处置不同：**

| 情况 | 结果 |
|---|---|
| 语料里**有**这个作者，却用裸名字引 | **拒绝**——请改成 `{{cite:...}}` |
| 语料里**没有**这个作者 | 警告——**这处引用无据** |

第二种要认真对待。遇到它只有两条正路：

```bash
oss lit add <DOI> --run <运行目录>    # 把那篇文献抓进语料，然后正常引用
```

或者**改写这句话，不做具名归属**。**不要绕过去。**

> ⚠️ **姓能匹配，人不一定是同一个。**
> 实测踩到过：论文里的「Duncan」是 Otis Dudley Duncan（1967 年那本经典），
> 而语料里的 Duncan 是 Greg J. Duncan——**照提示改就会引错文献**。
> 所以提示里会给出**作者全名**；同姓多人时会全部列出，**工具不替你认定是哪一位**。

### 引用存在，不等于转述得对

编号是真的、年份是对的、DOI 能查到——**内容仍然可以是歪的**。

```bash
oss lit verify --run <运行目录>
```

它把每一处引用的**论文原话**和**被引文献的标题+摘要**配成对，先做机器比对：

| 结果 | 含义 |
|---|---|
| 支持 | 转述里的概念在摘要里找到了 |
| **存疑** | 有可映射的概念但**一个都没命中**——可能张冠李戴 |
| **核不了** | 没有摘要，或转述里没有可映射的概念 |

**「核不了」不是「存疑」。**语料里往往只有一半文献带摘要，
把「没摘要」算成「可疑」会立刻变成满屏假警报。

**机器只能抓明显的张冠李戴。**细微的过度引申（把相关说成因果、
把某一国的结论说成普遍规律、把「部分下降」说成「消失」）只有跨模型抓得到：

```bash
oss review <运行目录>/citation_check.json --kind citations --level deep --run <运行目录>
```

### 数字是真的，不等于话是对的

占位符堵住了「编一个 0.032」，但堵不住「在真的 0.188 旁边写『效应在减弱』」。
`oss paper check` 现在会核这几条：

| 检查 | 结果 |
|---|---|
| `{{...p}}` 渲染成 0.42，句子里说「显著」 | **拒绝** |
| `{{...p}}` 极小，句子里说「不显著」 | **拒绝** |
| 功效判 `fail` / `gray`，局限里一个字没提功效（描述类按精度判的，提精度也算） | **拒绝** |
| 共线诊断报「严重」，全文没提共线 | **拒绝** |
| 系数为正而句子里的方向词向下（反之亦然） | 警告——中文里「减弱 −0.785」也通顺，所以不硬拦 |
| `verdict_fragile` 为真而正文没报敏感性 | 警告 |
| 结果句里出现「证明」「证实」 | 警告——**统计显著不等于证明** |

**它抓不到什么，你要知道**：方向词描述的是**派生量**而非系数本身时，规则看不出来。
「三重交互为 +0.188，说明均衡作用在增强」这句话是错的（正的三重交互意味着**减弱**），
但系数确实是正的、方向词也向上，机械规则判为一致。
**这一类只能靠跨模型审稿。**

### 什么会被拦

| 写法 | 结果 |
|---|---|
| `效应为 0.032` | **拒绝**——裸小数 |
| `{{result:tab9.coef}}`（不存在的估计） | **拒绝**——占位符解析不了 |
| `样本 360 个` | 警告——整数不拦，但它跟结果里的数值相同 |
| `2021 年的数据` | 放行——年份 |
| `第 3 节` | 放行——序号 |
| `分箱显示呈非单调形态`（而 `binned` 是空的） | **拒绝**——见下 |

规则是**禁止小数**：统计结果几乎总是小数，而年份、样本量、节号都是整数。

### 拿分箱图做形状断言，文件里必须查得到

`oss figure --kind marginal` 会自己算一遍斜率去画图，
**但 `plan.json` 里没声明 `binned` 的话，`results.json` 里查不到那几个数**。

于是「分箱显示 2006 最高、2008 最低、2010 回升」这种句子，
**读者无从复核**——图里有、文件里没有，等于「相信我」。

先看 `results.json`：

- `diagnostics` 里有「**分箱：没算**」 → 那几个数不存在，**别写这类句子**
- `binned` 非空 → 可以写，而且**具体数值要用占位符** `{{bin:...}}`

要写这类句子又想留出处，就回到 `plan.json` 补 `binned` 后重跑 `oss run`。

**这个问题被跨模型审稿在两次独立运行里各抓到一次**，
所以现在是硬拦，不是警告。
