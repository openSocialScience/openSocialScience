# 中文论文（`--- lang: zh`）

**什么时候读这份**：缺省就读这份（`lang` 缺省 `zh`），或调用明确带了 `--- lang: zh`。
只有用户明说写英文论文（`--- lang: en`）才别读——那时的规矩在
[english-and-style.md](english-and-style.md)。

**大原则：换的只是语言，不换任何门。**占位符、三张表、图注表注、过程词黑名单、
新颖性门、审稿循环、处方处置——全部照旧，它们本来就认得中文。

## 起稿

```bash
oss style template --lang zh --out <运行目录>/paper.md     # 带风格包：oss style template <刊名> --lang zh
```

模板即通例：正文节编「一、二、……」；摘要下一行**关键词**（3–5 个，分号隔开）；
文末英文 **Abstract + Keywords**（多数中文期刊要求双语摘要，两份摘要的数字用同样的占位符，
内容对应，不许一边多说一边少说）；参考文献由 `{{references}}` 生成。

## 标点

**引号用弯引号 `“”`，不要用直角引号 `「」`。**嵌套用 `‘’`。

依据是 GB/T 15834《标点符号用法》——横排简体的引号就是 `“”`；
`「」` 是竖排与港台的用法。**这不是口味问题**：语料里 28 篇真发表的中文期刊论文，
`“”` 用了 3355 处，`「」` 一处都没有。

书名、期刊名、文件名用书名号 `《》`。变量名、列名这类代码标识符用反引号，
不要套引号。

其余照 GB/T 15834：句号 `。`、顿号 `、`（并列词之间）、逗号 `，`、
分号 `；`、冒号 `：`、破折号 `——`（占两个字位）、省略号 `……`（占两个字位）。
夹在中文里的阿拉伯数字与西文单词前后不加空格由排版处理，正文里正常写即可。

## 语言的规矩

- 正文**全中文**。保持原样的只有：数字与占位符、变量名（`log_gdppc`）、英文人名与刊名、
  统计术语的通用缩写（DID、OLS、I²）
- **不许中英混杂句**（"我们用 staggered DID 估计了 effect"——不行；
  「我们用分批双重差分估计」——对。首次出现可括注英文：「分批双重差分（staggered DID）」）
- 标题不超过 20 字；显著性写法照旧（p 值、置信区间），「显著」不等于「证明」
- 图**一律 `--lang zh`**——中文稿里嵌英文版的图，校验会拦（跟英文稿嵌中文图对称）
- 表头由渲染器按稿子语言自动出中文（变量 / 估计值 / 标准误），不用你管；
  **稳健性 `label` 在计划阶段就要用中文写**（它原样进森林图和稳健性表）

## 引用与文献

- 照常 `{{cite:}}` / `{{citep:}}`，中英文献都从语料引；中文文献先由用户从知网导出、
  `oss lit import` 进语料（见主链环节 2），**语料里没有的照旧不许引**
- 叙述式渲染成「张三（2020）」、括注式「（张三，2020）」，由渲染器处理。
  风格包的须知指定了顺序编码时，叙述式自动排成「**张三**^[1]」——**作者名留在正文里、
  编号作上标**（裸编号当主语的「[1] 认为……」不成句）。你照常写 `{{cite:}}`，不用管体例
- **体例**：导出 Word 时参考文献缺省按 **GB/T 7714 著者-出版年**排，也就是正文夹注
  「（张三，2020：162）」加文末参考文献表——《社会学研究》《社会》《社会学评论》这一路的通例。
  风格包的须知写了顺序编码就按顺序编码。都由 citeproc 排，**不要手工编号**。
  给人看的 `paper_rendered.md` 里引用仍显示「张三（2020）」——那是审稿用的中间产物，
  交付物 `paper.docx` 里才是最终体例

## 局限里关于中文文献的说法

语料里**有**导入的中文记录时，不写「中文文献未覆盖」，写实际情况：
「中文文献来自作者在知网的检索与导出（N 篇，检索式见留痕），不是系统性检索」。
一篇中文记录都没有时，照旧写中文覆盖是盲区。

## 交付

`oss paper check / render / export` 全部照旧。没带 `--style` 时导出的 Word 用标准中文
稿件排版：正文宋体小四、1.5 倍行距、首行缩进两字符，标题黑体纯黑，**表是三线表**，
摘要与关键词楷体五号，表题图注居中，表注小五号，参考文献悬挂缩进、按 GB/T 7714 著者-出版年。
带 `--style` 的按期刊模板与须知。

**节的顺序**（中文稿）：正文各节 → `## 参考文献` → `## Abstract`（英文题名、摘要、关键词）。
英文摘要排在参考文献**之后**，这是中文社科期刊的通例；排在前面 `oss paper check` 会报警告。

**标题前必须空一行**。紧贴在段落下面的 `## X` pandoc 认不出，Word 里会变成上一段末尾
一串裸露的「## X」。导出时会自动补，但 `oss paper check` 也会报出来——源稿里就补上。
