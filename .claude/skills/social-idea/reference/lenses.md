# ③ 发散与 ④ 收敛

## 为什么起点不能只有文献

老流程从「文献空白」一个起点出发。这条路被实证打过：文献缺口驱动的找题会**系统性收窄**
探索范围——只往文献记录充分的地方去、产出现有想法的变体、**恰恰漏掉那些没有文献覆盖的路径**。

而且作者自己承认的局限大多是套话（样本有限、未来可扩展），真正的大空白**没人承认**。

所以文献降为**四个起点之一**。它仍然有用，但不再是矿脉。

# ③ 候选生成（发散）

**看得见**：研究方向、数据的**形状**（不是变量清单）、环节 2 的语料。

## 四个起点并列

| 起点 | 从哪儿起 | 怎么问 |
|---|---|---|
| **异常现象** | 这个方向上有什么讲不通、反直觉、跟常识对不上的事实 | 「都说 X 会带来 Y，可为什么这里反过来？」 |
| **识别机会** | 这个**形状**允许什么识别策略 | 面板 → 固定效应 / 双重差分；有断点 → 断点回归；多轮 → 时间变化 |
| **理论张力** | 这个方向压着哪几个理论，它们之间哪儿有张力 | 「A 理论预测正向、B 理论预测负向，什么设计能把它们分开？」 |
| **文献局限** | 前人自陈的局限（老流程那一套，降为四分之一） | 从读书卡的「局限」原句起，**不从标题猜** |

> **「识别机会」看的是骨架，不是内容。**「这是个体层面的单轮横截面，所以做不了时间变化」
> 是设计层面的启发；「这份数据有 `income` 这一列，所以研究收入」才是数据出题。两者不是一回事。

**读书卡没有或局限栏全空**，说明这次只有标题和摘要可用：**方法缺陷类的空白挖不出来**。
要在收尾说明里标明这一类是空的，**不是不存在**。同样，先看语料 `notes` 里的覆盖率警告——
它已经把覆盖率翻译成了后果。

## 六个透镜降级为追问工具

| 透镜 | 它问什么 |
|---|---|
| `mechanism-gap` | X→Y 很稳健，但**通过什么路径**？ |
| `identification-upgrade` | 老关系——有没有**新政策冲击、自然实验或断点**能干净地识别它？ |
| `scope-condition` | **在什么条件下这个结论会失效？** |
| `contradiction` | 两派文献打架——什么**调节变量**能调和它们？ |
| `theory-collision` | 两个理论对同一现象**预测不同**——设计能分开它们的检验 |
| `measurement-gap` | 焦点构念只有有缺陷的代理——能不能**测得更好**？ |

**透镜不再是生成器，是每个起点内部的追问工具。**起点决定从哪儿起，透镜决定怎么往下问。
每个起点配两三个用得上的透镜就够，**不做全交叉**——四源 × 十透镜是组合爆炸，产出的是重复不是多样。

学科额外的四个（`new-data-window` / `untested-assumption` / `context-transfer` / `temporal-shift`）
按 [discipline-profiles.md](discipline-profiles.md) 开。

> ⚠ **`context-transfer` 和 `temporal-shift` 有强制门。**
>
> 这两个出来的候选，**必须附带「为什么结果应当不同」的理论论证**才算 idea。
>
> 「没人在 Z 国做过」**不是贡献**；
> 「这个理论假设了劳动力市场 X，而 Z 国不成立，所以符号该反转」**才是**。
>
> 论证说不出来的，自报 `transfer_rationale: null`、标为高风险，**但仍然进入候选池**——淘汰不是这一段的事。
>
> 这是社科版对 ML 那句「Apply X to Y 是最低级的研究 idea」的替代——**那句话在社科里是错的，不能照搬。**

## 产出 15–20 项

**量先够。**模型堆到一定数量后多样性会塌、开始重复自己，这一点靠提示词调不掉，
只能靠起点分散 + 数量托底。四个起点各出四五条，凑到 15–20。

**不作评价。**哪怕你觉得某条很蠢，也留着。

产出数写进 `ideas.json` 的 `generated_n`——**这一栏是不变量二的载体**，
后面每一步都拿它对账。

# ④ 机械筛除（收敛）

**看得见**：完整变量清单（`oss profile`，不带 `--shape`）。

> **只许淘汰，不许生成。**看见有意思的变量就想添一个题是本能，而那正是数据出题。
> 候选数在这一段**一条都不会变**——淘汰的与分流的都留在文件里，变的只是标记。
> 数一下条数还等不等于 `generated_n`，就知道有没有违规。

## 第一步 · 机械去重

union 所有起点的产出，按研究问题聚类近似重复的。

**只做机械相似度判断。永远不要因为「这个弱」而丢掉一个候选。**

## 第二步 · 机械处置：三条分流、一条淘汰

**这一步不判断质量、新颖性、理论贡献或有不有趣。**只按机械可核实的事实处置，
而且**处置分两种，不要混**：

| 判出来是这样 | 怎么处置 | 为什么 |
|---|---|---|
| **焦点构念在这份数据里无任何可用题项** | **分流**到清单乙 | 换份数据就能做，题本身没毛病 |
| **分析层次不匹配**（题问个体，数据只有国家层汇总，或反过来） | **分流**到清单乙 | 同上 |
| **期数 / 单位数撑不起所声称的设计** | **分流**到清单乙 | 同上 |
| **伦理不可行**（无正当理由的欺骗、脆弱人群无保护、知情同意不可行、隐私上无法链接） | **淘汰** | 换数据也救不了 |

> ⚠ **这四条里，只有「伦理不可行」是淘汰。**前三条都是「**这份数据**缺东西」，
> 而不变量三说得很清楚：**数据不可及不降权**。把它们淘汰掉，等于用一道机械的门
> 悄悄执行了「把研究降级成这份数据恰好允许的那些题」——正是不变量三要防的事。
>
> 分流的动作是三件：留在 `ideas` 里、编号写进 `unreachable`、
> `needs_extra_data` 写清**缺什么、去哪拿**。

> ⚠ **判「无任何可用题项」之前，必须回数据包全集再搜一次。**
> 真跑 r20260916_netdem 的教训：V-Dem 有 1818 列，环节 1 只取了 6 列进运行目录，
> 于是「网络自由度」被写成「本数据没有」——而 `v2mecenefi`（政府互联网审查力度）
> **本来就在包里**。你看到的变量清单是**取过列的子集**，不是数据的全部。
>
> ```bash
> oss data columns <包名> --search "<构念的几种叫法，逗号分隔>"
> ```
>
> 搜得到就回环节 1 把列取进来，不要写进清单乙。

> ⚠ **第一条最容易判错，而判错的方向是致命的。**社科的变量名天生简陋——一份叫
> 「政府信任」的数据里，列名可能是 `a35`、`b12`。**按列名字面搜不到，不等于这个构念不存在**。
> 找不到就先把候选列摆出来自己判，判不了就标注存疑往下走，**不要判死**。

**老的那条「完全没有识别路径」已经删掉**：有面板数据时「面板结构」本身就算一条识别路径，
所以那道门谁也拦不住，真跑 7 个候选淘汰 0 个。识别路径的**强弱**归 ⑤ 与环节 7.5 的识别审计管，
不归这里。

**不要因为「设计看起来复杂」淘汰**——那写进备注，不是淘汰理由。

被淘汰的（只有伦理那一条）与被分流的**都留在文件里**，各自写清楚是被哪一条处置的。

# 每条候选必填的几栏

- **`source_lens`** —— 四个起点里的哪一个：`anomaly` / `identification` / `theory` / `literature`。
  丢了它就没法回答「哪条路产出高」，也没法在某条路系统性产出垃圾时把它关掉。

- **`lens`** —— 哪个透镜追问出来的。跟上一栏并存不是重复：`source_lens` 答「从哪儿起的」，
  `lens` 答「怎么问出来的」。

- ****`research_type`**** —— 这道题想下什么结论：`causal` / `descriptive` / `measurement` / `simulation`。
  **按结论定，不按方法定**：想说「X 影响 Y」就是 `causal`，哪怕只打算用普通回归；只描述分布与趋势是 `descriptive`；
  主张是新量表或新指标是 `measurement`；要跑仿真是 `simulation`。**不许为了躲识别审计把因果问题标成描述**——
  陪审团会判，`oss run` 与论文措辞检查也会拦；输入带 `--- type:` 时按这一类出题，问法要跟类型一致
  （标描述就别用「是否导致」这种问法）。

- **`transfer_rationale`** —— 只有 `context-transfer` / `temporal-shift` 需要。为空即标高风险，但仍进候选池。

下面两栏缺了就是强信号，**照样写出来、标成空**，让后面的人判：

- **`theory_hook`** —— 进入哪个理论对话。**注意：这一栏在 ⑥ 查重定位时才填得实**，
  发散阶段先留你的判断，⑥ 用检索结果校正。为空是**强负面信号**：进不了任何理论对话的想法不是 idea。

- **`value_if_null`** —— 结果为空时这研究还成立吗。答不上说明这个 idea 的价值绑在结果方向上，
  **那是 p-hacking 的根源**。

写完先查格式再存：

```bash
oss schema ideas --example
```

存到 `<运行目录>/ideas.json`，然后往下走 ⑤ 经验预检（[prescreen.md](prescreen.md)）。
