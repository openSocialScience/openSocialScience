# 社科的 idea 跟 ML 的不是一回事

七条结构性差异，决定了不能照搬 ML 那套：

| # | 差异 | 对找 idea 的影响 |
|---|---|---|
| 1 | 受控实验通常做不了 | idea 生死取决于**有没有外生变异**，不取决于假设有不有趣 |
| 2 | 理论对话是发表门槛 | 说不出自己在推进或挑战哪个理论的 idea，顶刊发不了 |
| 3 | 构念不可观测，测量本身就是贡献 | 「怎么测」是 idea 的一部分，不是实现细节 |
| 4 | 结论受时空限定 | 情境 / 人群 / 时期的迁移**是正当贡献**，不是增量灌水 |
| 5 | 发表偏倚严重，空结果几乎发不了 | 风险评估跟 ML 反过来 |
| 6 | 伦理审查是硬前提 | IRB 可行性属于 idea 阶段 |
| 7 | 数据通常是别人为别的目的收的二手数据 | 约束是「现有数据里有没有能测这个构念的题项」 |

**质性研究不在范围内。**民族志、深度访谈、扎根理论走的是「现象 → 理论建构」，
不是「假设 → 检验」。透镜、功效、识别门对它们全是错的。
遇到本质上是质性的方向，**说明并停止**，不要产出假设形状的东西。
