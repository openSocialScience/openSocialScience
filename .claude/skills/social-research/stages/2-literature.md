# 环节 2 · 文献检索与精读

> **这一环改成双通道了**（idea 重构设计稿第五节②）：用户自己带来的文献**全文精读**，
> 领域检索**只扫标题摘要、不精读、不建空白地图**。
> 理由是下一环要发散，而灌进去的文献越详细，模型越倾向于把现成的东西重新组装一遍——
> 这一点有实证（给最少上下文时模型才调用内部知识做连接）。

## 输入
- 用户的研究方向（拆出核心构念）
- **可选**：用户自带的文献（入口 `--- refs: <题录导出文件 / PDF / 存 PDF 的目录，逗号分隔>`）
- `run_state.stage == "2-literature"`

## 双通道

| 通道 | 做什么 | 为什么 |
|---|---|---|
| **用户指定文献** | **全文精读**，抽「局限」原句、写读书卡 | 他检索过、筛过、亲手下载过——**确定相关**。精读它们比按排名抓前 20 篇划算得多（验收跑里前 20 篇只有 8 篇沾边），也绕开了开放获取拿不到全文那个老问题 |
| **领域检索** | **整个语料只扫标题摘要**；再从里面挑少量精读 | 给发散当燃料，不是给它灌输 |

> ⚠ **「只扫」说的是整个语料，不是一篇都不精读。**发散段的「文献局限」那个起点要的是
> **作者自陈的原句**，而原句只有精读才拿得到。所以：
>
> - **用户给了自带文献**：精读就用他那批，领域检索纯扫（这是最省的情况——他挑的确定相关）
> - **用户没给**：从领域检索结果里挑 **5–8 篇**精读，够那个起点有原句可用就行。
>   不是二十篇——老流程精读二十篇是为了建空白地图，而空白地图已经不是唯一起点了。

**两个通道都要跑：用户自带文献不得替代领域检索。**他给三篇同一流派的，
模型顺着它们想，等于把「找题越找越窄」这个毛病放大了一轮。

跑完报一句**覆盖偏差**：「你给的 N 篇集中在 X 阵营；检索另见 Y、Z 两派也在争这个问题」。
让他知道自己给的那批覆盖了什么、漏了什么。

自带文献**按量分两路**，别混成一路：

| 量 | 视作 | 处理 |
|---|---|---|
| **≤ 20 条** | 精选读物 | **不筛**，全部精读。用户挑的就是他要的，筛掉等于替他做决定 |
| **> 20 条** | 检索结果（知网一次导出几百条是常态） | 照跑 `oss lit screen`，筛完再从留下的里挑精读 |

分界值用户可以覆盖，但**有默认，不要每次问**。

### PDF 的元数据：三层往下退

`oss lit import` 吃题录导出文件（RIS / EndNote / RefWorks / NoteExpress），也吃 **PDF 或整个 PDF 目录**。
PDF 里没有结构化题录，元数据只能从正文找，所以分三层，跟 `oss data search` 查构念同构：

| 层 | 条件 | 做法 | 标注 |
|---|---|---|---|
| 1 | 首页印着 DOI | 取 DOI 反查权威题录 | 正常 |
| 2 | 没有 DOI | 抽标题去检索，**高度吻合**才采用 | 正常 |
| 3 | 仍不可得（多数中文 PDF） | 记下标题猜测 | `[UNVERIFIED]` |

> **第三层照样进语料**——它是用户亲手下载的，**查不到不等于这篇不存在**。
> 但标了 `[UNVERIFIED]` 的**引用之前要用户确认**，或者请他补一份题录导出文件（题录管元数据、PDF 管全文，最可靠）。

PDF 的全文会同时落进 `reading/`，可以直接写读书卡；抽出来太短的（扫描件、只有版权页）不算全文，索引里会注明。

## 产出
- `<运行目录>/literature.json`（检索式按**理论阵营**写，`阵营: 检索式`；检索式用**概念块**；滚雪球进来的记录 `via` 记来路）
- `<运行目录>/screening.json`（**你写**：每篇纳入 / 排除，排除的写理由）
- `<运行目录>/reading/<id>.txt` 与 `reading/index.json`
- `<运行目录>/reading_cards.json`（**你写**：问题 / 数据 / 设计 / 发现 / 作者自陈的局限逐字引原句 / 跟本研究的关系）

## 检索式的写法：概念块
块内同义词用 OR，块间用 AND，多词的同义词加引号，**最核心的概念放第一块**（命中不足时工具从最后一块开始丢）：

```
义务教育与生育: ("compulsory schooling" OR "schooling reform" OR "education expansion") AND (fertility OR childbearing OR "family size")
```

两到三块，每块一到四个同义词。**不要写成八个词的裸词袋**——OpenAlex 要求所有词都命中，实测八个词 4 条、三个词 219 条。

## 完成条件（全部满足才进环节 3）
- 至少三个阵营各一条检索式（支持的一派、反对的一派、方法的一派），**没有阵营是 0 条**；0 条先换词重搜
- `literature.json` 的 `notes` 每一条都读过，覆盖缺口记下来，环节 7 写进局限；看到「自动降档」要明白那次少命中不是空白证据
- `oss lit screen` 通过：每篇都判过，排除的写了理由；排除超过七成说明检索式跑题，重搜
- `oss lit snowball` 滚过一轮（筛过之后滚，种子只在纳入里取），新增的也筛过了
- **用户带了文献的**：`oss lit import` 导过；两个通道都跑了；覆盖偏差那句话说过；`[UNVERIFIED]` 有几条说过
- `oss lit fetch` 拿过；点名相关的用 `--ids`，不只靠 `--top` 的词重合排序；**滚雪球拉进来的文献 `--top` 基本排不上**（标题摘要不带检索词），要从筛选结果里 `--ids` 点名
- 每篇精读一张卡；`oss lit cards` 校验通过（**局限引文必须能在原文里找到**）
- 卡的「数据」那一栏**有名字就写名字**：写「26 国人口与健康调查（DHS）」「CFPS 2010–2020 四轮」，
  不写「多国生育调查」「48 个发展中国家的微观数据」——后者等于没说。
  **这一栏是缺数据时唯一有出处的线索**：一篇真发表的论文真用过它，说明它确实存在、
  而且本领域真在用。写虚了，后面开数据清单时就只剩模型凭记忆瞎猜
- **中文情境的题**：历史层（`--zh`）查过、该导入的导入了；语料里**一条中文记录都没有就不许在论文里写「首次」「尚无研究」**
- `run_state.stage` 推进为 `3-ideas`

## 禁止
- 把 0 命中当成"没人做过"的证据（可能是检索式让 OpenAlex 打空，也可能是那个源坏了）
- 没读全文就写"首次""尚无研究""nobody has"
- 引文写成"大概是这个意思"——找不到的引文会被拒绝
- 只读了摘要还硬填局限栏：**空着比编着诚实**
- 筛选时全部纳入——语料里总有沾词的无关文献，全纳入多半是没看
- 拿用户自带的那批**替代**领域检索（两个通道都要跑）
- 把 ≤20 条的精选读物也送去 `oss lit screen` 筛（那是替用户做决定）
- 把 `[UNVERIFIED]` 的记录当成已核实的题录去引用

## 中文文献

**先认清一件事，别在这儿浪费时间**：三个免费学术源**都不收录中文 CSSCI 社科刊**。
2026-09-25 实测（题目：宗教信仰 × 捐赠）：

- `oss lit search` 主库捞回 19 条，**只有 2 条是研究论文**，其余是「感谢某道长捐书」
  「省档案馆接受捐赠档案资料」「捐赠仪式在某清真寺举行」这类活动通讯，元数据还坏（年份标成 1900）
- **中文历史层 0 条**（白名单 25 本刊，OpenAlex 里有记录的 20 本、**共 23 条源记录**）
- Crossref 按刊名查《社会学研究》，返回的是《社会科学研究进展》《智慧教育》——**不是真 CSSCI 刊**

**所以中文那半靠三条路，缺一条就是盲的**：

1. **2018 年前：历史层**。`oss lit search --zh '阵营: 中文检索式'`（写法与阵营同英文，可给多条）。
   只查 OpenAlex 里的中文核心刊白名单，覆盖**基本止于 2018 年**，而且常常是 0 条。
   **`--zh` 要跟英文检索式写在同一条命令里**——`oss lit search` 重跑会整份重建语料，
   只有导入的记录保得住；`--zh` 与英文检索式至少给一条。

2. **你自己上网搜，下全文，再导入**（2026-09-25 加）。**这是中文那半的主力，不是备胎。**

   你有网页搜索，`oss` 没有（做网页搜索要付费密钥，开源项目不该强迫用户先买一把）。
   所以这一步的分工是：**搜是判断，归你；验是计算，归工具。**

   做法：按阵营组中文检索式搜 → 把候选全文下到一个目录（`.pdf` 或 `.htm` 都收）→

   ```
   oss lit import <那个目录> --run <运行目录> --camp <阵营>
   ```

   **中文社科有相当一批刊开放全文**，实测下得动：`html.rhhz.net`（《社会》《南方经济》）、
   `jpa.sysu.edu.cn`（《公共行政评论》）、`ccj.pku.edu.cn`（《经济学季刊》）、各高校院系仓库。

   导入时工具会替你**挡掉不是研究论文的**。判据是**有没有学术引用**，两条路任过其一：
   有参考文献列表，或者满篇 `《……》` 与 `Author (2012)` 这类引用片段
   （**第二条是给脚注体例的刊留的**——《中国社会科学》这一系整篇没有「参考文献」四个字）。
   活动通讯、院系动态、名录页、法规原文两条都不占。

   被挡的逐条报在 `data.rejected`：**里面要是有真论文，那多半是全文没下全或抽文抽坏了，
   重下或换个来源，别绕过门。**

   **下载用 `curl -fL`，`-f` 不能省。** 不加 `-f` 时 HTTP 403/404 的错误页会被
   当成正文存成文件（实测 85–2516 字节），一整批错误页就这么混进语料。
   工具有一道兜底（`n_broken`），但**兜底不是让你省掉 `-f` 的理由**。

   下载还有个坑实测撞到过：**有的期刊站就是不可靠**。`jpa.sysu.edu.cn`
   （《公共行政评论》）实测 **9 次只成 2 次**，给到 180 秒超时加三次重试也一样；
   失败的那些里，有的是彻底连不上，有的**下到一半就断**——文件看着有几百 KB、
   PDF 头也对，但抽不出一个字。

   工具会把截断的判成「判不了」而不是「不是论文」（照收并报警），
   但**读书卡做不出来**。看见 `n_undecided` 不为零：加大超时重下一次，
   **还不行就换来源**（同一篇论文常常在作者主页、院系仓库、中国社会学网上另有一份），
   别在一个站上耗。

   线性化 PDF 自报全长（文件头里的 `/L 1052261`），跟实际大小一比就知道截没截断。

3. **知网/万方导出的题录**。去知网检索，选中题录 → 「导出 → EndNote 格式」下载文件（RefWorks、
   NoteExpress 也解析）；万方导出 RIS 或 EndNote。然后 `oss lit import 文件 --run <运行目录> --camp <阵营>`。
   **题录带摘要，质量比第 2 条高**，但要用户有知网权限——**没有就别卡在这儿**，走第 2 条。
   解析按各家的官方导出样式写，**真实文件只用合成样本核过**——摘要断在半截、卷号或 DOI 没抽到，
   多半是这一家的样式没覆盖到：把文件脱敏后放进 `tests/` 当夹具，再补解析。
   UTF-8 或 GBK 都能读。

4. **导入完接着筛**：`oss lit import` 只是把文献并进语料，**导入不等于筛过**。
   跑 `oss lit screen` 只判新增的，已判过的不用重写。

> ⚠ **第 2 条这批要在论文的方法节里说清两件事**：来自网页检索、由模型提供候选，
> 不是结构化学术源；**同一检索式在不同时间结果可能不同，这一批不可完全复现**。
> 它是**补**不是**换**——OpenAlex 仍是主源，网页这条只补它够不着的中文。

限制，写进论文的局限：

- **导入的记录没有 OpenAlex 编号**，`oss lit snowball` 对它们无效（滚不出参考文献与引用）
- **走第 3 条（题录导出）的拿不到全文**，只有题录和摘要（`--top` 倒排得上：中文按子串匹配）——
  这批的读书卡只能写到摘要级，局限栏多半空着（空着比编着诚实）。
  **走第 2 条（自己下全文）的没有这个问题**，全文落进 `reading/`，读书卡能写到局限级
- **只收中英文**：日文、韩文的题录跳过并报数（纯汉字写的日文标题分不出来，会当中文进来）
- **网页检索那一批不可完全复现**（第 2 条），方法节要照实说

换词重搜（`oss lit search`）会**保留导入的记录及其筛选判定**——它们是手工搬进来的，
没有任何检索源能把它们找回来；**其余记录（英文与历史层命中）按新检索式整份重建**。

## 命令
```bash
oss lit search '阵营A: ("…" OR "…") AND (… OR …)' '阵营B: (…) AND (…)' '阵营C: (…) AND (…)' --zh '本土: 义务教育 生育' --run <运行目录> --limit 20   # --zh 跟英文检索式写在同一条里：只查核心刊白名单，止于 2018 年前
oss lit import ./中文全文/ --run <运行目录> --camp 本土研究     # 你自己上网搜、下下来的全文（.pdf/.htm 目录）；工具挡掉不是研究论文的，看 data.rejected 与 n_undecided
oss lit import 知网导出.txt --run <运行目录> --camp 本土研究   # 知网/万方导出的题录并进语料；导入不等于筛过
oss schema screening --example        # 筛选判定的格式；读 literature.json 的标题摘要，逐篇判
oss lit screen --run <运行目录>        # 校验并盖到语料上
oss lit snowball --run <运行目录>      # 从纳入的前 8 篇往后拉参考文献、往前拉引用；--seeds 可点名
oss lit screen --run <运行目录>        # 只判新增的（已判过的不用重写）
oss lit fetch --run <运行目录> --top 20
oss lit fetch --run <运行目录> --ids 10.2139/ssrn.975892,W2069096636
oss schema reading --example
oss lit cards --run <运行目录>
```
走 MCP（oss_lit_search）时直接给原始检索式，不要加任何反斜杠；走 shell 用单引号包住。AND / OR 只认大写，不支持 NOT。
