# 环节 2 的散文：阵营、覆盖、全文与新颖性

检索式从用户的方向里拆出核心构念来组，可以一次给多条。**每条前面写它属于哪个理论阵营**
（`阵营: 检索式`）——理论对话至少有两派，支持你的一派、反对的一派、方法的一派各出一条。
评审第七条：验收跑整群缺了威权回应性、数字威权主义、民主与健康三群文献，
「替代论」的理论支撑只剩一句猜想。语料会按阵营记命中，**哪个阵营 0 条一眼看得见**——
0 条先换词重搜，不能当空白证据。

**检索式用概念块**：`("compulsory schooling" OR "schooling reform") AND (fertility OR childbearing)`。
OpenAlex 要求所有词都命中，八个词的裸词袋实测 4 条、三个词 219 条，于是语料就剩那几条，
而没有任何一步会报错。块内同义词 OR、块间 AND，
多词同义词加引号（OpenAlex 的 OR 只绑相邻的单词），**最核心的概念写第一块**——
命中不足 10 条时工具自动从最后一块开始丢，最少留两块，并在 `notes` 里说清降了几档。
看到「自动降档」就要明白：**降档前的少命中不是「没人做过」的证据**。

**检索完先筛再读。**语料里总有沾词的无关文献（高被引的 COVID 治理、债务危机），
工具的相关度判据只是「沾没沾词」，判不了「是不是同一件事」。读 `literature.json` 每篇的
标题摘要，按 `oss schema screening --example` 的格式写 `screening.json`：每篇「纳入 / 排除」，
排除的写一句理由。`oss lit screen` 校验后盖到语料上，之后 `--top` 只排纳入的。
排除超过七成说明检索式跑题，回去改检索式重搜，不要硬读。

**筛完滚一轮雪球。**主题检索够不着两种东西：经典（常是书、章节、工作论文，`type:article` 挡掉了）
和最新的争论（还没积累关键词）。第一期实测把每源取量翻 2.5 倍召回不动——它们不在关键词能到的地方。
真人做综述靠的是引文链：`oss lit snowball` 从纳入的前 8 篇往后拉参考文献（经典在这）、往前拉引用
（按被引取最有分量的后续工作），每篇两次调用。第二期实测三题整体召回从 0.14 / 0.06 / 0.05 到
0.33 / 0.15 / 0.38。滚进来的记录 `via` 记着从哪篇来的，阵营继承种子。**滚完要再筛**：
`oss lit screen` 只要求判新增的，已判过的不用重写；改口会在警告里列出来。想指定种子用 `--seeds`。
**滚进来的文献 `--top` 基本排不上**：排序只看标题摘要跟检索词的重合，经典的标题多半不带你的检索词。
读哪几篇，从筛选时标纳入的里面挑，`--ids` 点名去拿。

读 `literature.json`，注意：

- `abstract_coverage` 太低 → 抽不出作者自陈的局限，「方法缺陷」类空白就找不到
- `citation_coverage` 为 0 → 召回率探针不可执行
- **`hits_by_source` 里有 0，或 `hits_by_query` 里某条是 0** → 那不是「没人做过」，是检索式坏了（发现源现在基本只有 OpenAlex，某条打空就整条没了）
- **`notes` 里每一条都要读**——它把数字翻译成了后果
  （「摘要覆盖 29%」→「方法缺陷类空白因此检测不到」）
- 源不可用（额度耗尽、超时）**不是**「没人做过」的证据，覆盖是残缺的

## 中文为什么只能导入

三条理由，一条比一条硬：

1. **没有 API。**知网、万方、维普、国家哲社中心全都没有开放接口。知网自己是 DOI 注册机构，
   它的 DOI **不进 Crossref**——按 DOI 也解析不出来。
2. **抓取器脆且是法律灰区。**页面一改就坏，而且踩着服务条款走。这种东西不该进默认路径。
3. **导出是用户本来就会做的动作。**在知网检索、勾选、点「导出 → EndNote 格式」，
   是每个中文文献综述都要做一遍的事。工具吃这个文件，是唯一诚实又合法的路。

所以中文那半分成两条路：**2018 年前走历史层**（`oss lit search --zh`，只查 OpenAlex 里的
中文核心刊白名单），**2018 年后走导入**（`oss lit import`，按知网的 RefWorks / EndNote /
NoteExpress 与万方的 RIS / EndNote 官方样式解析，UTF-8 或 GBK 都读）。**真实导出文件只用
合成样本核过**：各家版本的标签集与大小写有出入，遇到解析不全的，把文件脱敏后放进 `tests/`
当夹具，照着补标签表。

**导入的三条限制**（都要写进论文的局限）：

- **没有 OpenAlex 编号**——`oss lit snowball` 对这批记录无效，滚不出参考文献也滚不出引用；
  中文的经典要靠自己在知网里翻引文，或者多导一批
- **拿不到全文**——只有题录和摘要。这批的读书卡只能写到摘要级，
  「作者自陈的局限」栏多半空着，**空着比编着诚实**
- **只收中英文**——日文、韩文的题录跳过并在结果里报数。纯汉字写的日文标题分不出来
  （码位跟中文一模一样），会当中文进来；知网、万方的导出里这种极少

导入完接着 `oss lit screen` 只判新增——**导入不等于筛过**。

**历史层为什么要白名单**：不限源的 `language:zh` 回来的是满库低端刊与学位论文，
冒充「核心刊历史层」进语料，下游没有一步会报错。白名单收了 25 本社科核心刊，
**其中 OpenAlex 里真有中文版源记录的只有 20 本**——《经济研究》《中国社会科学》
《中国行政管理》《教育研究》《开放时代》这五本一条都没有。这五本在历史层里是彻底的盲区，
它们的文献只能靠导入。`oss doctor` 会把这三个数（清单本数 / 有记录本数 / 源记录条数）报出来。

## 先读透，再想题目

检索只给了标题和一半的摘要。**好题目藏在文献的局限章节里**——作者自己承认没做到的事——
这一步把最相关的 20 篇拿到本地，读透，写成读书卡。

```bash
oss lit fetch --run <运行目录> --top 20          # 有开放获取链接的抽全文，没有的只留摘要
oss schema reading --example                     # 读书卡的格式
```

**`--top` 排出来的只是候选，读哪几篇是你的判断。**排序靠词的重合，
高被引的无关文章（COVID 治理、债务危机）会因为沾了「government」「health」混进来——
验证跑里前 20 篇只有 8 篇跟题目沾边。先在 `literature.json` 里按标题和摘要
挑出**直接相关**的那些（核心构念在标题里的优先），点名去拿：

```bash
oss lit fetch --run <运行目录> --ids 10.2139/ssrn.975892,W2069096636,10.3982/ecta14392
```

没找到的 id 它会报出来，不会静默跳过。

它会报**来源层级**：全文 / 仅摘要 / 仅元数据。全文不到一半时它会说——
那意味着「方法缺陷」类空白这次系统性地缺失，要写进局限。

全文按顺序试：记录自带的链接 → OpenAlex 全部开放位置 → 落地页里的 PDF 链接 → Unpaywall → CORE。
后两个要在 `.env` 里配 `UNPAYWALL_EMAIL`（任何邮箱）/ `CORE_API_KEY`（免费申请），
没配 `oss doctor` 会说；**配上通常能多拿到三成全文**。拿不到的每一篇都记着为什么。

> 🔴 **没读过全文，不许说「首次」「尚无研究」「nobody has」。**验收跑 22 篇精读只拿到 1 篇全文，
> 论文却写 "nobody has put informational cost in the moderating position"——评审：「你没有能力知道
> 有没有人做过，这一条单独就足以让编辑退稿」。`paper check` 会拦：精读集全文不到 3 篇或不到一半，
> 新颖性主张一律拒绝；够了也要把范围写出来（"among the studies we could read in full"）。
> 全文不够就去补（配全文源、点名 `--ids` 再拿），补不到就改口。

然后**你**读 `reading/<id>.txt`，每篇写一张卡到 `reading_cards.json`：
问题 / 数据 / 设计 / 发现 / **作者自陈的局限（逐字引原句）** / 跟本研究的关系。

```bash
oss lit cards --run <运行目录>                    # 校验：每条局限引文必须能在原文里找到
```

**找不到的引文会被拒绝。**「大概是这个意思」正是空白地图最不能建在上面的东西。
只读了摘要的卡，局限栏多半是空的——**空着比编着诚实**。
