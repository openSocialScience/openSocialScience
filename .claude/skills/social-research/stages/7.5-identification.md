# 环节 7.5 · 因果设计的审计（因果研究，或从因果降级、仿真货箱时）

## 输入
- `plan.json` 的 `research_type` 是 `causal`，或锚点冻结时是因果、后来降级成描述的（锚点冻的是因果，审计照做）；**用 `ols_fe` 下因果结论的也要审**。**老计划没写 `research_type` 的**照旧按估计量判：`estimator` 是 `did` / `did_cs` / `event_study` / `iv` / `rdd`，**或者写了 `treat_time`**；**仿真货箱**（运行目录有 `sim_state.json`）不论类型都进本环节，走下面「数据来自仿真货箱时」那几条
- `<运行目录>/results.json` 的 `diagnostics`：双重差分族读「平行趋势」（联合检验）「预检功效」「breakdown 值」
  「对照组」「处理前平衡」「批次异质性」；工具变量读「第一阶段强度」「有效 F」「AR 区间」「tF 区间」「OLS 对照」；
  用 `ols_fe` 下因果结论的读「敏感性分析」「稳健值」「Oster δ」「E 值」。**没算的照实写「没算」**
- `run_state.stage == "7.5-identification"`

## 产出
- `<运行目录>/review_plan.json`（跨模型审计报告）
- `route.json` 里新增的 `audit_N` 处方，每条都有处置

## 完成条件（全部满足才进环节 8）
- **在主目录跑**过 `/social-identification <运行目录>`
- 上面列的机器诊断都读过并照抄进收尾说明
- 审完**再跑一次 `oss route`**；每条 `audit_N` 为 applied / disclosed(--why) / dismissed(--why)
- 判 FAIL 且替代设计试过也穷尽的，已留痕 `oss trace save --step design_alternatives_exhausted`，然后按 `../rules/stop-conditions.md`：**保留原设计，全文降级为关联，审计的每条意见写进局限**，继续往下走（回环节 7 把局限改写进去）
- `run_state.stage` 推进为 `8-review`

## 禁止
- 另开目录跑审计（**分目录等于绕过门**）
- 把"判不可靠"当成"通过"
- 用结果变量的处理前走势筛主样本（那是让检验必然通过，不是让设计站住）
- 因为审计 FAIL 就**换题目、换数据、问用户**（带 `--- checkpoint: design` 的除外，见 `../rules/ask-user.md`；规矩全文见 `../rules/stop-conditions.md`）
- 在论文里写"审计指出…"——写那个局限本身

## 数据来自仿真货箱时

机器已算的双重差分族诊断（平行趋势 / 预检功效 / breakdown 值 / 对照组 / 处理前平衡 / 批次异质性）仍要照读——
它们是从 `results.json` 算出来的，跟数据来路无关。但**审计真正要判的问题
换了一套**：仿真数据不是观察数据，传统混淆问句在这里问不出真问题，
`/social-identification` 盯的清单换成下面四条：

- **rep 够不够**：`sim_state.json` 的 `downgrade` 为 `true`（rep < 3）时，不必
  回头换设计——「初步/探索性」表述已经是诚实的应对，环节 7 的措辞规矩会接住
  它，这里不因此判 FAIL
- **条件平衡**：仿真各条件用**同一个人群池按条件复制**出来（同一批 agent
  档案，只是分进不同 `condition`），这在设计上就是天然平衡——协变量不会因为
  选择进入某条件而系统性失衡，写明这一点即可，不必再跑传统的协变量平衡检验
- **敏感性跑没跑**：核对环节 5 `robustness` 清单里的跨 rep 留一有没有真跑过、
  效应方向和显著性有没有变
- **污染声明核过没**：`sim.meta.json` 的 `contamination_note` 写了没有，写的
  是不是「不确定也要写」而不是留白搪塞

**威胁模型也换了**：仿真论文的头号威胁**是模型伪影，不是观察性混淆**——
提示词措辞怎么带偏了回答、模型的先验立场压过了条件差异、多轮对话里的记忆
污染让后面的波次预判了自己该说什么。传统混淆问句（"有没有遗漏变量同时影响
处理和结果"）问的是数据生成过程里人的选择，对仿真数据没有意义——**不要
机械套用**这一套，套上了也审不出真问题，只会让审计变成走过场。
