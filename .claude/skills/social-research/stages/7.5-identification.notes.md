# 环节 7.5 的散文：门为什么要跟上

如果 `plan.json` 的研究类型是因果（老计划没写类型的：`estimator` 是 `did` / `did_cs` / `event_study` / `iv` / `rdd`，**或者写了 `treat_time`**）
（`ols_fe` 带交互项那种，`oss run` 已附带跑了逐年展开），**这一步不能跳**。
**在主目录跑**——审计报告和之后的 `design_alternatives_exhausted` 留痕
要跟论文在同一个目录里，导出时的门才看得见。

```
/social-identification <运行目录>
```

系统能说出「是它造成的」了，门就必须跟上。机器已经算好一批诊断
（双重差分族的平行趋势、预检功效、breakdown 值、对照组、处理前平衡、批次异质性；
工具变量的有效 F、AR 区间、OLS 对照；普通回归下因果结论的稳健值、Oster δ、E 值），
这个 skill 先带你读它们，再把机器判不了的那一半交给别家模型：
**为什么是这些地方先改？**

审完回来**再跑一次 `oss route`**：审计的每条设计级意见都会变成一条处方（`audit_N`），
能改设计的改，改不了的 `--disclose` 写进局限——**写那个局限本身，不提审计**。

> **平行趋势通过不等于外生。**它只说明处理前那几期没显著分化，
> 而选择可以发生在更早、或基于不可观测的东西。
