# 环节 1 的散文：合并、重塑、诊断图

六千列的调查文件（GSS、CGSS、CFPS）**必须挑列**，挑哪些列是你的判断（看码本，`oss data info <名>` 有链接）。
**要申请的数据集（CGSS、CFPS、WVS）系统下不了**：`get` 会退出并打印怎么申请、放哪——
**原样转告用户，然后停**，不要拿别的数据顶替。用了数据包的，论文数据节必须引它（出处文件里有引用格式，`paper check` 会查）。

```bash
oss profile <数据文件> --run <运行目录>
```

读一遍产出的 `profile.json`。重点看三样：

- `structure.kind` —— 面板？截面？**重复截面？**（重复截面做不了 DID）
- `structure.nesting_levels` —— 嵌套层级，决定层次匹配
- 各变量的 `within_variation` —— **为 0 的列会被固定效应整个吃掉**

有任何一项让你觉得这份数据撑不起用户的方向，**现在就说**，
不要往下走二十步再说。

## 要拼两份数据的时候

**不要自己写拼接脚本。**用：

```bash
oss merge <主数据> <要拼进来的> --on country,year --run <运行目录>
oss profile <运行目录>/merged.csv --run <运行目录>     # 拼完重新画像
```

**拼数据是这条链上最危险的一步**，因为它错了不报错。真数据上量过一次：
两份「国家-年」数据按国家名直接拼，**丢 25.3%、30 个国家整个消失**——
一边写 `Korea (the Republic of)`，一边写 `South Korea`。

而丢掉的那 29 个国家里，民主国家比例比留下的**低 10 个百分点**，
那份数据研究的正是民主化。**等于挑着跟研究主题相关的那批扔掉。**

`oss merge` 丢超过一成会**直接拒绝**。它的输出分四类，含义完全不同：

| 它说什么 | 意思 | 你该做什么 |
|---|---|---|
| **某个键的取值在对面整列里都没出现** | 口径不一致 | 做对照表，**能救回来** |
| **每个键单独看都在，是组合缺** | 那几格真没数据 | **对照表救不回来**，写进局限 |
| **丢掉的那批系统性地不同** | **样本被筛过一遍** | 必须写进局限；如果被筛的是处理变量或结果变量，结论带偏 |
| **长得像的候选** | 待你确认 | **逐个核**，确认后写成对照表 |

对照表是一个两列的 CSV（左表写法, 右表写法），用 `--map` 传进去：

```bash
oss merge a.csv b.csv --on country,year --map crosswalk.csv --run <运行目录>
```

**候选是给你看的，不是答案。**`Korea` 到底是韩国还是朝鲜，
工具不替你认定——**替人做了不该做的认定，制造的错误比拦下的更难发现**。

确实要接受损失，用 `--allow-loss 0.13` **显式说出来**，
并且**把这个数字和上面那条「系统性地不同」一起写进论文的局限**。

## 画像说「这看起来是宽表面板」的时候

那是**每人一行、各轮变量并排**的面板数据（`happy_1` `happy_2` `happy_3`）。
画像会判它 `cross_section`——按文件当前形状说没错，
**但照截面分析会把面板结构整个扔掉**，个体固定效应、个体内变化全用不上。

```bash
oss reshape <数据文件> --run <运行目录>              # 转成每人每轮一行
oss profile <运行目录>/long.csv --run <运行目录>     # 对长表重新画像
```

**不要自己写重塑脚本。**这是算的活，归工具箱——
自己写没有任何东西会去核你写对没有，轮次拼错了回归照跑、结果照出，
**不报错，只是量错了东西**。（真跑一次时正是这么绕过去的。）

转换只做摞行。**量表反向、取对数、转哑变量它一概不做**——
那些是你的判断，要自己做，并在论文的「数据与方法」里交代构造式。

构造变量的脚本放在运行目录里叫 `prep.py`，**每个构造式一段注释写依据**
（「1990 年前互联网补零：WB 序列 1990 年起、当年中位数即为 0」），
然后对产出的文件重跑 `oss profile`。这些构造式没有任何门核它——
它们是这条链上唯一没人核的计算，所以论文方法节必须**逐条**交代，
审稿人会对着 `prep.py` 看。

它的输出里有三句必须读：

- **「是猜的」** —— 编号列没认出来。猜错了每一行会挂到错的人身上
- **「不是每轮都有」** —— 那个变量某一轮**根本没问**，跟「答了但缺失」不是一回事
- **「不随时间变」** —— 这些列会被个体固定效应整个吃掉，系数估不出来

**画三张诊断图看一眼**——回归表回答不了「这份数据能不能撑起这个设计」，图能：

```bash
oss figure structure --run <运行目录>                        # 结构判定的证据
oss figure missing   --run <运行目录>                        # 缺失率 × 时间
oss figure clusters  --run <运行目录> --cluster-col <列名>    # 簇大小与设计效应
```

- **`structure`** —— 每期行数、每个个体出现在几期。
  编号被回收（每轮问卷从 1 重编）时，`structure.kind` 会判成重复截面并**不给个体标识**，
  图上能看见依据。**判成面板却上个体固定效应，等于把不同的人当成同一个人。**
- **`missing`** —— 「整体缺三成」和「前两轮一条都没有」是两回事。
  后者意味着这个变量在早期队列上根本不可用，跨时期比较要重新划窗口
- **`clusters`** —— 簇数低于约 30 时聚类稳健标准误本身有偏
