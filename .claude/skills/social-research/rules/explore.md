# 探索规则

**想试一试（审稿人说「加个控制变量看看」、处方说「缩窗口试试」）——走探索通道：**

```bash
oss run --explore --for <处方id 或 review-rN> --plan <探索计划文件> --run <运行目录>
```

- 必须 `--for`：说清回应哪条意见；没有意见就没有探索（还没有 `route.json` 就先 `oss route`）
- 只许改控制变量、样本筛选、固定效应、聚类、交互、稳健性清单；**改结局、处理变量、估计量就是换题**，门会拒绝；**不许换数据**（完整名单以门为准，被拒时它会点名）
- 结果进 `explore/`，**不进论文、不进稳健性表、占位符引用不到**；写进 `--why` 的数字**不算出处**，别指望靠它把探索的数字洗进正文
- 同一条意见最多 5 次成功探索，再试要 `--why`
- **不许用 python 直接跑回归**——那些数字没有出处，写进论文会被 `paper check` 拦；探索也只走 `oss run --explore`

## 四件事一律不许自己写脚本

| 想干什么 | 走哪条命令 | 自己写会怎样 |
|---|---|---|
| 拼两份数据 | `oss merge` | **错了不报错**：按国家名直接拼丢了 25.3%、30 个国家整个消失 |
| 宽表转长表 | `oss reshape` | 轮次拼错回归照跑、结果照出，**只是量错了东西** |
| 算统计功效 | `oss power` | 事后算的功效不是事前功效，审稿人第一条就问 |
| 跑任何回归 | `oss run` / `oss run --explore` | 事故里自写 213 段回归、换题 4 次、`paper check` 拒绝 25 次 |

唯一允许自己写的脚本是 `prep.py`（构造变量），**每个构造式一段注释写依据**，
并且论文方法节要**逐条**交代——它们是这条链上唯一没人核的计算。
