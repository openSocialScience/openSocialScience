OpenSocialScience is a toolkit for quantitative social science research that runs inside agents such as Claude Code and Codex. Given a research direction and a dataset, it carries out literature search, topic selection, econometric analysis, writing and cross-model review in turn, and exports a Word manuscript formatted for the target journal.

## 🚀 Quick start

### Install with your agent

Send this message to your agent.

```text
Install https://github.com/openSocialScience/openSocialScience by following docs/INSTALL.md in the repo.
```

### Install manually

Requires Python 3.11+ and [pandoc](https://pandoc.org).

```bash
git clone https://github.com/openSocialScience/openSocialScience
cd openSocialScience
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev,figures,stats-formats,excel,causal,reading]"

cp .env.example .env    # add your API keys
oss doctor
oss install-skills
```

### Start a study

Open your agent in the project directory and enter a research direction, the data and the discipline.

```text
/social-research Educational expansion and family background --- data: data.csv --- discipline: sociology
```

The paper is saved to `runs/<run>/paper.docx`. See the [user guide](docs/使用说明.md) for more options.

## 🔍 Number provenance

Every statistic in the manuscript is written as a placeholder such as `{{result:main.coef}}` and filled in from `results.json` at render time. A hand-typed decimal fails the check. See [Architecture](docs/ARCHITECTURE.md) for the checks at each stage.

```text
paper.md           The effect is {{result:main.coef}} (SE {{result:main.se}}, p {{result:main.p}}).
paper_rendered.md  The effect is 0.188 (SE 0.026, p < 0.001).
```

## 📦 Built-in data

QoG, V-Dem, GSS and CGSS are ready to use, for example `--- data: pack:qog`. Indicators from the World Bank, OECD and Our World in Data can be searched and downloaded with `oss data search` and `oss data fetch`. Simulation data comes from `/social-sim`, see [simulation](docs/user/sim-box.md).
