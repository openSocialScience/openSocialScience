## 差序格局的城乡与代际分布

以熟人圈三类对象的信任均值减去对陌生人的信任，度量信任随社会距离递减的幅度。
全国加权总体中，城市非农户口居民与农村居民的这一落差相差 −0.303 个作答档次，
出生越晚差距越大，改革开放后出生者为 −0.511。

两类居民对陌生人的信任未见明显差别，差距主要出在熟人一端。
抽样权重与复杂抽样设计进了估计、标准误和功效。12 项稳健性检验，`oss eval` 31 项全过。

## 公共服务获得感测的是谁的获得

「获得感」应当指向个人所得，但全国性调查里常用的四道题问的是对「我国目前公共服务总体」的评价。
本文检验这套量表更接近本人得到的东西，还是对社会整体的判断。

同一省份内，社会公平感每高一级量表分显著上升；而参保与个人收入未检出正向关联。
换一个同为五级自评、只把参照层次改为自己家的效标，公平感的系数仍大出约一倍半到两倍。
结论是量表更接近对社会整体的判断，不宜当作个人获得的尺度来比较人群。
23 项稳健性检验，`oss eval` 26 项通过、must 级 0 项未过。

## 宗教参与、捐赠与对陌生人的信任

用同出生省份、出生年段与性别群体中他人的平均宗教活动频率作借力变量，考察宗教虔诚度与捐赠、
与对陌生人信任的关联。捐赠一侧初看与概率高 0.044 相关联，但三项检查先后动摇了它：
加入省级民族构成与城镇化率后区间即含零；同一借力变量对一个与宗教无关的安慰剂结局（自评健康）
也给出区间不含零的估计；处理测于调查当年，而捐赠问的是上一年，时序是反的。

论文因此不下因果结论，正文改为论证这类同群借力变量为何不足以识别宗教参与的后果。
31 项稳健性检验，`oss eval` 30 项通过、must 级 0 项未过。
