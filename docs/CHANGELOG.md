# 更新日志

写法参照 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，新版本在上，版本号按 [语义化版本](https://semver.org/lang/zh-CN/)。

## [0.1.0] - 2026-10-21

第一个公开版本。

### 研究流程

- **九个环节的研究链**：数据画像、文献检索、找题目、可行性（绑定构念、算功效）、写计划、跑分析、写稿、
  识别审计（因果研究才有）、审稿与收尾，每一步都记在 `trace.jsonl` 里
- **四类研究**：因果、描述、测量、仿真，按想下的结论分类，各有自己的计划要求和检查
- **程序检测**：计划校验、探索检测、锚点检测、研究类型检测等，不通过就不能往下走；
  `oss eval` 对照说明书逐条打分
- **跨模型审稿**：审稿人和执行者用不同家族的模型，默认最多两轮

### 估计与数据

- **估计量**：`ols_fe`、`did`、`did_cs`、`event_study`、`iv`、`rdd`、`describe`，
  另有二元与有序 logit、多层模型、逆概率加权与双稳健估计
- **调查数据**：能认出权重、分层和初级抽样单位；所有估计量都加权，标准误按抽样设计算
- **因果诊断**：工具变量报有效 F 和 AR 区间，事件研究报预检功效，`ols_fe` 的因果结论报 Oster δ 和 E 值
- **仿真**：OASIS、AgentSociety 的输出先验货再入库，见[仿真货箱标准](user/sim-box.md)

### 文献与写作

- **文献**：检索、滚雪球、取全文、读书卡、引文核对；中文文献可以从网页全文导入
- **写稿**：统计数字只能写成占位符，渲染时从分析结果填入
- **风格包**：《社会学研究》《管理世界》《中国社会科学》，管到版式、字体和字数，导出 Word
- **图表**：默认中文，表格用三线表，表里印变量的中文名

### 接入

- **五个 Agent**：Claude Code、Codex、dsh、WorkBuddy、openclaw；`oss mcp serve` 提供 32 个 MCP 工具
- **一句话安装**：对 Agent 说一句话，它照着 [`INSTALL.md`](INSTALL.md) 装好整套工具
