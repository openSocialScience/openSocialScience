## 两套体例是照实物定的，不是照指南猜的

**中文**——五本刊、**19 张**真发表的图：《管理世界》2015（顶刊）、《公共行政评论》2021、
《华南师范大学学报（社科版）》2023、《湖北经济学院学报》2024、《东北财经大学学报》2023。
其中**三张独立的事件研究图**，三家的画法完全一致：

| 量到的 | 我们照做 |
|---|---|
| **一张彩色都没有** | 黑 + 灰阶 + 点形 + 线型 |
| 图四周有完整边框 | 四边都画 |
| 图内不放标题，图题排在图**下方**居中 | 图内无标题；图题进旁注 JSON，导出时 pandoc 排成 Word 题注，正好落在图下方 |
| 误差棒是虚线 | 逐年展开图的误差棒改虚线 |
| 图例排在图下方横向一行 | 同 |

**英文**——Social Forces 六篇（顶级社会学刊）里的 **19 张**图：

| 量到的 | 我们照做 |
|---|---|
| 彩色**可以**用（六篇里一篇用了 Stata s2color），但三篇是灰阶 | 保留 Okabe–Ito 配色 |
| 多系列用**线型 + 点形 + 灰度**三重区分（soad063 那张最典型） | 照做——这正是不靠颜色的那一半 |
| 只留左、下两条轴线 | 同 |
| 图题在图下方左对齐，排成「**Figure N.** Title.」 | 图题进旁注 JSON |
| 衬线字体 | Times / Nimbus Roman |

《社会学研究》的投稿须知查过，关于图只有一句「每张表格、图均应达到出版印制要求」，
**没有任何细则**——所以只能看实物。

## 两边共同的一条：图要经得起黑白印刷

原来的橙 `#D55E00` 与蓝 `#0072B2` 是按**色盲**可分挑的（Okabe–Ito）。
转成灰度是 **119 vs 87——12% 的明度差，印在纸上等于没有区别**。

**色盲友好和黑白友好是两件事**，从前只解决了前一件。

所以：中文这边整套走灰阶；英文这边保留颜色，**另外加点形与线型**——
主效应用**菱形**（森林图里菱形表示焦点估计本来就是通行做法），其余用圆点；
逐年展开图处理前用**空心点**、处理后用**实心点**。在线看是彩色，印出来或复印照样分得开。

[`灰度自检/`](灰度自检/) 里是把两套都转成灰度的结果，可以直接核这一条。

## 两层图，两种待遇

| | 图 | 给谁看 | 产物 |
|---|---|---|---|
| **进论文** | 主回归系数、稳健性森林图、逐年展开、分箱斜率 | 读者 | PNG + **矢量 PDF** + **旁注 JSON**（语言、建议图注） |
| **诊断** | 结构判定、缺失率、簇与设计效应、共线 VIF | 执行者自己 | 只有 PNG |

分两层不是省事：**诊断图是用来发现错误的，不是用来展示的**。把它们一起塞进论文，
读者要替作者做本该在分析阶段做完的检查。

## 英文图上不许留中文

**方框比没有图更糟**——它看起来像图能用，实际读不出来。

`coef` 与 `robustness` 一直把中文标签滤掉，**`marginal` 漏了**：它直接印原始列名，
于是中文列名 + 英文衬线字体排成一排方框。2026-09-24 补上，
滤不掉的（没有英文标签）记进旁注的 `cjk_labels`，**由导出那一步拦住**，不让它静悄悄进论文。


## 缺省是中文（2026-09-25 改）

`oss figure` 的 `--lang` **缺省 `zh`**，写中文论文和中文期刊体例的图是缺省路径；
**用户明说要写英文论文才传 `en`**，那时图也跟着走英文体例。

## 图内不放教学式注记

翻遍中英两边 **38 张**真发表的图，**没有一张有教学式注记**。所以两句话去掉了：

- 逐年展开图的「竖虚线左边是政策实施之前。那几期本该贴着零线。」
- 分箱斜率图的「交互项假定这几条线是直的。弯的就说明规格错了。」

**但两样东西留着，而且改成两种语言都印**——它们不是教学话，是这次分析的事实：

| 留下的 | 为什么 |
|---|---|
| 平行趋势的**判词** | 验收跑里图上写「平行趋势未被推翻」、同一份 Word 的摘要写「联合检验拒绝了平行」，**一份文件自己打自己脸**。英文图从前一条判词都没有，是同一个洞的另一半 |
| 分箱斜率**哪几组没画出来** | **静默少一条线是最坏的**——图看起来正常，读者不会知道少了一半 |
